# Rediseño Web Doctor Clean (drclean.cl)

Nueva portada editorial y de interacción para Doctor Clean, empresa de lavado de alfombras, tapices, colchones y decapado de piso flotante a domicilio en el sector oriente de Santiago de Chile (+15 años de experiencia).

## Stack Tecnológico
- **React 19** + **Vite 6** + **TypeScript**
- **Tailwind CSS 4** (`@tailwindcss/vite`)
- **Motion** (`motion/react`)
- **lucide-react**

## Especificaciones de Negocio Respetadas
- **Cobertura:** Las Condes, Providencia, Vitacura, La Reina, Ñuñoa, Lo Barnechea (otras comunas RM con recargo a convenir).
- **Precios Base:**
  - Alfombra muro a muro: $3.500/m² + IVA (mínimo 15 m²).
  - Alfombra decorativa: $7.500/m² + IVA (mínimo 8 m²).
- **Método de Espuma Controlada:** Maquinaria suiza, hasta 80% menos agua, secado en horas, productos biodegradables con normas ISO 9001 e ISO 14001. Sanitización incluida sin costo adicional.
- **Tiempos de Secado:** Alfombras 8–24 h aprox. (verano); sillones 24–72 h; pisos 1–2 h.
